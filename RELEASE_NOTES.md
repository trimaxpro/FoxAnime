# 🦊 FoxAnime v1.0.0 - Initial Windows Desktop Release

We are excited to announce the official initial release of **FoxAnime for Windows** (v1.0.0)! 

FoxAnime is a high-performance, dark-themed desktop client designed for smooth, ad-free anime streaming with automated progress tracking and real-time title search.

---

## 🔥 Key Highlights

- 🍿 **100% Ad-Free 1080p Streaming**: High-definition video playback with zero ad interruptions, popups, or redirects.
- ⚡ **Instant Title Search**: Lightning-fast search lookup powered by real-time title indexing.
- ⏱️ **Auto Progress Resume**: Automatically saves your watch history and episode progress so you can jump back in anytime.
- 🎬 **Sakugabooru Dynamic Animation Background**: Landing showcase powered by real-time Sakugabooru animation background video streaming.
- 💻 **Native 60 FPS Windows Client**: Optimized desktop architecture for Windows 10 & Windows 11 (64-bit).
